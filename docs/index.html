O que ele limpa

As mesmas limpezas que ferramentas como o RAMMap fazem, num botão só.

Memória dos programas

Pede para cada processo aberto devolver a memória que está segurando sem usar.

Cache de arquivos

Esvazia o cache de arquivos do sistema e grava no disco o que estava pendente.

Lista standby

Libera a memória "em espera" que o Windows guarda, a culpada por algumas travadinhas em jogos.

Como usar

Leva menos de um minuto.

01

Baixe

Clique em "Baixar LimpaRAM.exe" e salve onde quiser. Não precisa instalar.

02

Abra como administrador

O Windows vai perguntar se permite alterações. Clique em "Sim", é necessário para limpar o standby.

03

Aperte o botão

Clique em LIMPAR RAM e veja quanto foi liberado. Pronto.

Um aviso honesto

O número de memória livre sobe na hora, mas isso não deixa o PC mais rápido por si só. O Windows usa a RAM sobrando como cache de propósito, e vai enchê-la de novo conforme você usa o computador.

Limpar ajuda mesmo em casos específicos: jogos com travadas por standby cheio, algum programa que vaza memória, ou antes de abrir algo muito pesado.

Perguntas

As dúvidas mais comuns.

O Windows mostrou "O Windows protegeu o computador". É vírus?

Não. Esse aviso (SmartScreen) aparece para qualquer programa que não tenha assinatura digital paga. Clique em "Mais informações" e depois em "Executar assim mesmo". O código é aberto e o .exe é compilado automaticamente pelo próprio GitHub a partir dele.

Por que precisa de administrador?

Para liberar a lista standby e o cache do sistema, o Windows exige permissão de administrador. Sem ela, só daria para limpar parte da memória.

Posso perder algum trabalho aberto?

Não. Nenhum programa é fechado. A memória que eles não estão usando vai para o disco e volta automaticamente se precisarem dela.

Não dava para limpar direto pelo site?

Não. Por segurança, nenhum site consegue mexer na memória do seu computador. Por isso o LimpaRAM é um programa que você baixa.
